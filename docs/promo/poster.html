核心特性 / FEATURES

GPU 硬件解码

启用 VK_KHR_video_decode_h265，NVIDIA / AMD / Intel 通用。

纯 GPU 上屏

解码 → 纹理 → Vulkan 交换链，全程不回读内存、不做 CPU 上传。

客户端更新自动适配

按导出名挂钩 FFmpeg，客户端更新换版本后自动重部署补丁并校验。

开箱即用

自带已编译的定制 Wine 运行时，用户不用编译、不用折腾依赖。
